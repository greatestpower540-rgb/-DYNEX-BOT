QUICK START

Make your first API request

Create a developer account, generate an API key, then call the DYNEX endpoint from your secure server.

cURL · Chat Completions
curl https://YOUR-WORKER.workers.dev/v1/chat/completions \
  -H "Authorization: Bearer dnx_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "dynex-chat",
    "messages": [
      {"role": "user", "content": "Hello DYNEX"}
    ]
  }'

Authentication

Send your key in the Authorization Bearer header. Never place secret keys in browser code, public repositories or mobile app bundles.
